# Nasa-Spherex-Mission

We are developing SPHEREx Explorer, a public-facing web application that transforms NASA's SPHEREx astronomical observations into an accessible platform for discovering moving and variable celestial objects. Users can enter Right Ascension (RA) and Declination (Dec) coordinates to retrieve observations of specific sky regions across different dates and visualize them through interactive time-lapse animations.
The platform integrates SPHEREx data releases, processes FITS images, organizes observations across six detector arrays, and applies scientifically compatible image co-adding techniques to improve the signal-to-noise ratio of faint astronomical sources. Additional capabilities include image blinking, subtraction, multi-band infrared visualization, and AI-assisted identification of potential moving objects and brightness variations.
